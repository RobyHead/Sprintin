# Sprintin

基于Unity的键盘音游，雏形出自我学习pygame时堆的屎山代码音游，现使用这个玩法进行Unity的初学，在ai帮助下火速出品。

## 玩法

- **4 轨下落式音符**：D / F / J / K 分别对应四条轨道
- **Tap**：普通单点音符
- **Hold**：长按音符，需按住并在尾部后松手
- **Ground**：地面障碍物，通过空格跳跃躲避
- 跳跃高度和滞空时间随BPM自适应，支持变BPM和变流速

## 技术要点

本部分内容都由ai总结：
- **音频同步**：基于 `AudioSettings.dspTime` 驱动游戏时钟，保证音画同步
- **谱面变速系统**：`SpeedTimeline` 支持任意时间点的流速变化，所有音符和背景通过积分距离统一计算位置
- **BPM 自适应跳跃**：根据当前 BPM 动态计算抛物线上升/悬停/下降时间
- **三级判定**：Perfect / Great / Bad 三层判定窗口 + Miss 兜底
- **场景转场**：`SceneTransitionManager` 实现 Outro → 加载 → Intro 的状态机，异步场景加载不黑屏
- **选曲系统**：JSON 驱动的多层曲库（Pack → Song → Difficulty），支持专辑封面加载与音频预览
- **对象池**：背景装饰物使用真正对象池循环复用
- **数据持久化**：PlayerPrefs 存设置，JSON 存储各难度最高分与全连记录
- **自定义谱面格式**：`.spr` 文本格式，见下方说明。配套从arc自制谱面文件转成.spr格式的工具。


## 谱面格式（.spr）

```
@bpm=120.0;
@offset=0;

(0, 120.0, 4.0);           # BPM 变化: ms, bpm, beatsPerBar
[1000, 2];                  # Tap: ms, key(1-4)
[2000, 1, 4000];            # Hold: ms, key, endMs
[3000, 0];                  # Ground: ms, key=0
{5000, speed, 2.0};         # 变速: ms, speed, multiplier
{6000, text, 500, 2000, 500, 这是一句话};  # 文字特效: ms, text, fadein, duration, fadeout, <content>
```
