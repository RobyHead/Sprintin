# Sprintin

> 一款 3D 音游，融合 4K 下落式与地面跳跃躲避障碍玩法 | Unity 6 + C#，单人两个月从代码到音乐到谱面全链路开发



## 核心特性

### 玩法基础
- **4K 下落式 + 地面跳跃**：D / F / J / K 对应四条空中轨道，空格键操控角色跳跃躲避地面障碍；跳跃滞空时长等于当前 BPM 下的一个四分音符
- **三种音符类型**：Tap（点击）、Hold（长按带尾判）、Ground（跳跃躲避）

### 游玩与结算
- **判定窗口**：Tap 和 Hold 音符判定窗口为 Perfect（±50ms）/ Great（±100ms）/ Bad（±150ms），超时自动 Miss；Hold 头部与尾部独立判定，尾部提供 100ms 提前松手容限；Ground 音符在 +50ms 处检查角色是否处于跳跃状态，处于跳跃中则 Perfect，否则 Miss
- **视觉反馈**：判定结果显示在场景中央地面，不同判定颜色不同，便于快速辨认；多押音符自动切换高亮材质以作区分；连击数达到 10 及以上时显示 Combo 计数
- **结果展示**：谱面结束后音乐渐弱淡出，自动弹出结算面板，展示最终分数、各判定数量与最大连击数；最终分数由判定类型贡献加权分数，最终归一化为 1,000,000 满分
- **快速操作**：按 R 重新开始、Esc 返回选曲，游玩中使用长按进度条防止误触

### 谱面效果
- **变速效果**：在谱面指定时间点插入流速变化，实现骤停、渐快、高速段落等设计
- **拉伸效果**：按指定时间区间对谱面做线性 / 缓入 / 缓出拉伸，类似谱面内变化流速
- **文字效果**：谱面进行时展示自定义文字，采用淡入 → 保持 → 淡出三段式显示，用于教程提示等场景

### 选曲列表
- **曲包分组浏览**：歌曲按曲包归类，A/D 切换曲包，W/S 切换歌曲；选中项自动吸附居中并放大
- **跳转上次游玩**：进入选曲列表后，自动选中上次游玩的歌曲与难度
- **游玩状态指示**：每首歌曲展示封面缩略图与状态指示器，按颜色区分各难度游玩状态——无谱面（灰）/ 未玩（白）/ 已玩（黄）/ 全连（粉）/ 全完美（青）；选中歌曲展示详细信息和最好记录
- **音频预览**：选中歌曲一定时间后播放预览片段，带淡入淡出循环；切换时快速切出平滑过渡

### 设置与校准
- **设置系统**：延迟偏移、音符下落速度、音乐音量；A/D 调整数值，W/S 切换设置项，选中项显示箭头提示并吸附居中；退出设置时自动保存
- **延迟校准**：校准面板定时播放提示音，在第三拍按下空格自动计算并调整延迟；同时提供视觉提示，可手动微调至舒适偏移

### 场景切换
- **过场动画**：页面和场景切换通过全屏面板滑入 → 加载 → 滑出的过场动画衔接
- **游戏启动**：启动游戏后进入标题动画，按任意键进入下一步：首次启动游戏时进入延迟校准 → 新手教程流程，后续启动游戏则进入选曲列表

## 技术亮点

### 音频时钟驱动
音游对时间精度要求高，游玩中时间基于 `AudioSettings.dspTime` 计算，以此驱动音符位置的计算，保障音符与音乐同步。音乐通过 `PlayScheduled` 调度，保障音乐起点与判定时间轴严格对齐。延迟校准系统使用同种方法计算延迟偏移，与游玩时延迟保持一致。`GameTime.HasStarted` 作为全局门控，在加载完毕后通过事件传播设置为真，所有功能同步启动。

### 变速谱面的距离计算
各音符使用基于谱面变速数据和音频时间系统的统一接口获取位置。计算音符位置时，对流速函数分段积分，将时间差转换为空间距离，再将结果乘上伸缩倍数，组合成多样的视觉效果。背景环境的移动速度也根据变速数据动态调整，保持与音符协调。

### 玩家跳跃系统
跳跃用五态状态机管理：`Idle → Rising → Holding / Conflicting → Falling → Idle`。总跳跃时间基于跳跃 BPM 计算，可能在跳跃期间变化；上升动作与下落动作的高度计算基于物理抛物线公式，角色位置与判定状态分离。总跳跃时间充裕时，角色完整上升、滞空、下落；跳跃时间较短时，角色在上升未完成时就计算下落，使用 `Conflicting` 状态处理上升的计算高度小于下落的计算高度的情况，使无法完全跳起时位置不突变，同时在上升过程中滞空时间增长时可以回退到 `Rising` 状态。总跳跃时间有最小值约束，保障高 BPM 场景的游玩手感。玩家在落地前一小段时间可以重新起跳，通过缓冲时间提升连跳手感。

### 音符与环境的生成
音符全量预生成，环境使用对象池管理。所有音符在解析后一次性 `Instantiate`，运行时零动态生成。判定后不直接执行 `Destroy`，而是隐藏并注销。避免频繁创建销毁对象影响性能。环境背景拆分为切片预制体，根据权重由对象池随机选择并拼接。

### 谱面解析管线
谱面处理分多个阶段接力完成。`ChartParser` 读入谱面文本，逐行分流到 Meta / BPM / Note / Effect 四个子解析器，解析后遍历音符列表标记多押音符；`ChartManager` 接手后将数据分配给对应的对象；最后全量实例化音符与小节线。

### 选曲列表的缓存与防抖
封面图在列表初始化时全部预加载并缓存到字典，切换歌曲时直接使用，避免加载时元信息与封面不同步的闪烁。预览歌曲在快速切换选曲时不播放，累积一定稳定时间后才触发加载。预览区间由歌曲元信息指定，循环播放预览片段，首尾做淡入淡出。

### 曲包结构与成绩持久化
曲包、歌曲用文件夹结构和 Json 文件维护，分根文件夹、曲包文件夹、歌曲文件夹三级，文件夹名为曲包、歌曲 id，在上一级 Json 文件中注册。存档结构为 `RootRecord → List<PackRecord> → List<SongRecord> → List<DiffRecord>` 四层嵌套，用序列化为 Json 文件持久存储，每次结算时保留更好的成绩。

### 设置系统的抽象与多态
设置项统一继承 `Option` 抽象基类，定义 `PersistKey`、`Increase()`、`Decrease()`、`Load(string)`、`Save()` 五个接口。`NumericOption` 实现带上下限和步长的数值型选项。`OptionListManager` 在 `OnEnable` 时遍历子级 Option 组件统一加载并传入 `OptionList`，`OnDisable` 时统一写入 `PlayerPrefs`，用组件生命周期管理持久化边界。

## 谱面格式（.spr）

```
@offset=0;                      # 谱面延迟偏移
@end=10000;                     # 手动规定谱面结束时间

(0, 120.0, 4.0);                # BPM 变化: ms, bpm, beatsPerBar
(0, 120.0, 0.0);                #   beatsPerBar 为 0 时设定跳跃 BPM，不为 0 时设定小节线 BPM
[1000, 2];                      # Tap: ms, key(1-4)
[2000, 1, 4000];                # Hold: ms, key, endMs
[3000, 0];                      # Ground: ms, key=0
{5000, "speed", 2.0};           # 谱面变速: ms, "speed", multiplier
{5500, "stretch", 5750, 1.5, si};   # 谱面伸缩: ms, "stretch", endms, multiplier, s|si|so
{6000, "text", 500, 2000, 500, "这是一句话"};   # 文字特效: ms, "text", fadein, duration, fadeout, "<content>"
```



## 如何运行

#### 直接游玩

- 解压游戏压缩包后打开 `Sprintin.exe`

#### 从源码运行

- 获取项目文件后用 Unity 6（6000.4.7f1 及以上）打开
- 打开 `Assets/Scenes/MenuScene.unity` 后点击 Play 运行

## 操作说明
- 游戏**完全使用键盘**操作，游玩谱面的键位由教程介绍，其余键位见各页面底部按键提示
- 启动游戏后会自动进入标题动画，按任意键进入下一步
- 从选曲页退出到标题后，按 Esc 直接退出游戏



## 项目结构

```
Assets/Scripts/
├── Gameplay/           # GameScene
│   ├── Config/             # 游戏时配置（流速、音量、延迟）
│   ├── Data/               # 谱面数据与解析
│   ├── Enums/              # 枚举类型（判定种类、难度档位）
│   ├── Environment/        # 背景对象池
│   ├── Lanes/              # 多轨道布局、各轨道输入 + 材质高亮
│   ├── Managers/           # 流程总管、时钟系统、坐标计算系统
│   ├── Notes/              # 音符 / 小节线 + 各管理器 + 判定核心
│   ├── Player/             # 玩家跳跃系统
│   ├── ResultPanel/        # 结算流程与成绩展示
│   └── UI/                 # 游戏时信息展示
├── Global/             # 跨场景
│   ├── Records/            # 最好成绩和持久化
│   └── SceneTransition/    # 场景切换和过场动画
└── Menu/               # MenuScene
    ├── CalibratePanel/     # 延迟校准
    ├── Managers/           # 面板编排、键盘输入管理
    ├── SelectPanel/        # 选曲系统
    ├── SettingsPanel/      # 设置系统
    └── TitlePanel/         # 标题页与入场动画
```

## 已知限制

- **无可视化制谱器**：当前使用第三方制谱工具产出谱面，再通过自研转换脚本转为 `.spr` 格式，特效语句需手动编辑。后续计划开发可视化编辑器，支持即时编辑与预览。
- **分辨率适配**：当前固定全屏游玩，未提供窗口模式与分辨率选项。后续计划加入窗口/全屏切换与分辨率枚举设置。
- **键位不可自定义**：游玩键位通过 Inspector 配置，暂不支持游戏内自定义。后续计划在设置中加入键位绑定功能。
